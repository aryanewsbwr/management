## 🌐 डोमेन (aryannewsagency.com) पर लाइव करने का तरीका (Deployment)

### विकल्प A: Vercel / Netlify / Cloudflare Pages (1-क्लिक मुफ्त और सबसे तेज़)
1. इस कोड को GitHub पर पुश करें।
2. Vercel या Netlify में नया प्रोजेक्ट बनाएं और रिपॉजिटरी लिंक करें।
3. Build command: `npm run build`, Output directory: `dist`.
4. अपने डोमेन `www.aryannewsagency.com` का DNS CNAME रिकॉर्ड Vercel/Netlify पर पॉइंट कर दें।

### विकल्प B: cPanel / Hostinger / GoDaddy शेयरर्ड होस्टिंग
1. रन करें: `npm run build`
2. प्रोजेक्ट के `dist/` फ़ोल्डर में बनी सभी फाइलों (`index.html`, `assets/`, `manifest.json`) को अपनी होस्टिंग के `public_html` फ़ोल्डर में अपलोड कर दें।
3. आपकी साइट तुरंत `https://www.aryannewsagency.com` पर लाइव हो जाएगी!
