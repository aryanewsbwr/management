# Modern News Agency Management System (PaperFlow Pro)

A modern, light-themed, responsive cloud web & multi-platform application for newspaper agency transactions, subscriptions, hawker routes, automated billing, and AI business intelligence.

## Features
- **Publisher & Publication Master**: Manage newspapers, magazines, day-of-week pricing matrix (Monday-Sunday copy rates), holidays, and supplements.
- **Customer Accounts & Subscriptions**: English & Hindi customer names/addresses, daily quantities, hawker assignments, discounts, and delivery fees.
- **Hawker & Route Distribution**: Delivery boys, region mapping, route priority, and daily distribution sheets.
- **Automated Monthly Billing Engine**: Calculates daily deliveries based on weekday rates, holidays, fees, and arrears.
- **Printable Invoices & Payment Receipts**: Physical bill print receipts and collection tracking (Cash, UPI, Cheque, Bank Transfer).
- **Retail Counter Sales & Wholesale Stock Purchases**: Daily over-the-counter sales and publisher stock invoices.
- **Groq AI Assistant**: Integrated natural language query assistant for instant dues, routes, and sales summaries in English & Hindi.
- **Database**: Supabase (PostgreSQL) cloud DB schema with local fallback engine.

## Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
